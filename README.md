# Interactive Science Virtual Labs & K-12 Teaching Tools

An open-source collection of lightweight, single-file HTML/SVG virtual labs and interactive classroom tools designed for primary science education.

## Features
- **Zero-Cost & Offline Ready:** Single-file HTML simulations that run smoothly on any browser or interactive smartboard without external dependencies.
- **Interactive Modes:** Includes "Explore" and "Challenge" modes to help students visualize concepts like plant and animal cells.
- **Bilingual Support:** Tailored for both English and Arabic science classrooms.
